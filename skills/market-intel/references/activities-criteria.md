# 活动情报判断准则（需求文档「活动情报」版块）

信源：活动行（huodongxing.com）等企业级活动平台。页面差分产出新活动条目后，AI 按
本准则判断并在 `judged.json` 的 `intel` 里产出带 `activity` 明细的记录。

## 记录契约（intel 记录 + activity 明细）

```json
{
  "change_id": "原样带回",
  "type": "活动情报",
  "significance": "normal | high（重点活动升 high）",
  "title": "活动名称",
  "summary": "一句话说明活动定位与目标人群",
  "url": "活动详情页",
  "sources": [{"name": "活动行", "url": "…"}],
  "activity": {
    "name": "活动全名",
    "time": "2026年10月31日 13:00-17:50",
    "location": "北京海淀…（线上写「线上」）",
    "highlight": "看点：面向谁、讲什么、为什么值得市场同事去（可含客户质量评价）",
    "signup_url": "报名链接（活动行 event 页）"
  },
  "notify": true,
  "notify_reason": "为何值得市场团队关注"
}
```

## 收录白名单（须同时满足）

1. **主题含出海相关词汇**（标题/正文/海报描述）：出海、跨境、全球化、游戏发行、
   短剧出海、Web3、AI、智能硬件；
2. **企业级（B2B）**：峰会、论坛、沙龙、展会、闭门会——目标受众是企业在职人员
   （技术/市场/产品决策者），能接触到潜在客户或生态伙伴。

## 绝对排除（黑名单）

- 一切 C 端生活娱乐活动：读书会、相亲、聚餐、亲子、个人培训班、兴趣社群；
- 明显面向个人开发者/学生的免费公开课（无企业决策者触达价值）；
- 拿不准时宁可漏报（C 端活动混入会直接消耗市场同事信任）。

## 判断要点

- `significance: "high"` 的条件：主题与八行业强相关（游戏出海、AI 硬件、短剧出海等）
  且规模可判断为行业级峰会（有知名主办方/赞助商），或历史活动中出现过 WebEye 目标客户；
- 主办方/赞助商名单是隐含线索源：出现八行业企业时，可同时为该公司抽 facts
  （`other` 事件，kind=partnership），活动与线索互相印证；
- `time` 用原文写法（含日期与时段），不要换算时区。
