# 市场情报可靠性修复计划与验收

基线：v0.6.9，`b278c7e21d9dbf2979bd7efe2bfce2fed8e5235f`。
范围：仅技能源码、离线测试、技能文档与必要生成索引。不重置真实工作区、不迁移历史数据、
不发送消息、不写线索池、不新增运行依赖、不推送 Git。用户已授权本地修复和分类中文提交。

## 逐项设计

| 项目 | 最小机制 | 改前复现／改后验收 | 状态 |
|---|---|---|---|
| 待判恢复 | 在快照推进前按稳定 ID 保存完整待判，不刷新首次发现时间 | 采集后不判断再采集；快照写盘失败后队列仍存在 | v0.6.10 完成 |
| 待判判空 | 新增 needs_judgment，保留 total 的新增统计含义 | 无新增但有携带待判时不得结束 | v0.6.10 完成 |
| 重判纠错 | 更新有效流水，旧值追加修订日志，已发送保护不撤销 | 修改摘要、撤回、已发文案修订；保留原 logged_at | v0.6.10 完成 |
| 入池查重 | 查询失败不创建；按 CLI offset 有限分页，结构异常和预算耗尽视为失败 | 模拟查询报错、第二页匹配，创建后补查失败不重建 | v0.6.10 完成 |
| 发送确认 | 只确认清单中的记录；保留同秒未发送项和未确认分片 | 产卡后新增、同秒新增、缺文件、重复提交 | 待实施 |
| 企业范围 | 明确 CN／非 CN、true／false 优先；未知才走关键词 | 外国企业上海参展、明确不出海、正常中国出海样本 | 待实施 |
| 事件去重 | 只自动合并有强一致依据的记录，其余仅候选提示 | 同公司不同产品不可合并；中文相同内容可合并 | 待实施 |
| 事件时效 | 融资按发生时间，不使用抽取时间替代；未来日期不命中 | 缺日期、旧日期、未来日期、近期日期；招聘观察语义不变 | 待实施 |

## 二次核查与提交

每批先查看目标入口及调用方，再补失败回归测试；实现后复查行为与失败边界，运行技能
全套测试、目标 lint／安全扫描和路径限定的 diff 检查。技能变更与自动生成元数据分开提交。
用户已有 `docs/pending-fixes.md` 修改不纳入本轮提交。

失败时不为测试通过放宽断言，不自动回写旧数据。并发多进程事务、事实人工纠错接口、
真实获客转化、全信源可用性与飞书实际送达不属于本次本地验收证明。

## 调研依据与限制

- [AWS 事务发件箱](https://docs.aws.amazon.com/prescriptive-guidance/latest/cloud-design-patterns/transactional-outbox.html)：借鉴可靠待办与幂等重试原则，不引入相关云服务。
- [Python 原子替换](https://docs.python.org/3/library/os.html#os.replace)：单文件替换不能证明多文件事务成立。
- [Apache Beam 时间语义](https://beam.apache.org/documentation/programming-guide/#watermarks-and-late-data)：区分发生时间与处理时间，不引入 Beam。
- 本机 `lark-cli base +record-search --help` 确认 offset 分页；未将 REST 参数假定为 CLI 能力。
- 安全边界：全部回归使用临时目录，外部接口仅模拟；本地通过不代表真实外部链路验收。
