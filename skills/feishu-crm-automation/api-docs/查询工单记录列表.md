# 查询工单记录列表

获取「工单」对象中符合指定条件的记录列表。Tips：可在 “目录>历史版本” 的接口文档中查看历史接口

## 请求方式
POST

## 接口路径
/v1/data/namespaces/ticket_management__c/objects/object_order/records_query

## 请求

### 请求头
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| Authorization | 必填 string | 传入应用 Token | T:f582c06c6ed14686b0ef... |
| Content-Type | 必填 string | 类型为 application/json | application/json |

### 请求体
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| select | 必填 string[] | 需要获取的字段，使用字段唯一标识符进行查询，关联字段可使用「.」进行下钻 | ["_id", "_createdBy"] |
| filter | object | 筛选条件，通过 JSON 格式指定条件。 | -- |
|   └─ conditions | object[] | 条件数组 | -- |
|     └─ operator | string | 操作符 | -- |
|     └─ left | object | 左值 | -- |
|       └─ type | string | 左值类型，只支持 "metadataVariable"，表示字段 | "metadataVariable" |
|       └─ settings | json | 字段具体值，以 JSONString 表示，格式：`{"fieldPath":[{"fieldApiName": "字段名","objectApiName": "对象名"}]}` | -- |
|     └─ right | object | 右值 | -- |
|       └─ type | string | 右值类型，只支持 "constant"，表示常量 | "constant" |
|       └─ settings | json | 常量具体值，以 JSONString 表示，格式：`{"data":"常量具体值"}` | -- |
|   └─ expression | string | 描述 conditions 之间的逻辑关系，从 1 开始下标，支持 `and` 和 `or` | "1 and 2" |
| order_by | object[] | 排序参数，field 为字段，direction 为方向。 | -- |
| group_by | object[] | 聚合参数，field 为参与聚合的字段。 | -- |
| page_token | string | 分页的 Token 值，由服务端生成。第一页需填写空字符串 ""，且不能与 OFFSET 一起使用。 | "" |
| use_page_token | bool | 是否使用 page_token 功能。默认为 False 。 | false |
| page_size | int | 期望服务端返回的记录条数，上限 500 条。默认值为 500。 | 100 |
| offset | int | 返回记录的偏移量，默认为 0。拉取全部记录时建议使用 ID 游标分页。 | 0 |
| need_total_count | bool | 是否返回符合条件的记录总数（Total）。默认为 False。 | false |
| query_deleted_record | bool | 是否查询已删除记录。 | false |
