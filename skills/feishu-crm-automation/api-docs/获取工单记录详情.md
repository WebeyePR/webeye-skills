# 获取工单记录详情

获取「工单」对象中指定的记录详情。Tips：可在 “目录>历史版本” 的接口文档中查看历史接口

## 请求方式
POST

## 接口路径
/v1/data/namespaces/ticket_management__c/objects/object_order/records/:id

## 路径参数
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| id | 必填 string | 查询记录的记录 ID | 12345678910 |

## 请求

### 请求头
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| Authorization | 必填 string | 传入应用 Token | T:f582c06c6ed14686b0ef... |

### 请求体
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| select | 必填 string[] | 需要获取的字段，使用字段唯一标识符进行查询，关联字段可使用「.」进行下钻 | ["_id", "_name"] |

## 响应
| 名称 | 类型 | 说明 |
| :--- | :--- | :--- |
| code | string | 响应码，0 代表成功 |
| msg | string | 响应描述 |
| data | object | -- |
|   └─ item | object | 记录详情 |
|     └─ _id | string | 记录 ID |
|     └─ lookup_c5de0a7f9a4 | object[] | 「抄送」，关联多条「用户」记录 |
|       └─ _id | string | 关联用户对象的记录 ID |
|     └─ _updatedBy | object | 「更新人」，关联「用户」对象 |
|       └─ _id | string | 关联用户对象的记录 ID |
|     └─ _createdAt | int | 「创建时间」，Unix 时间戳 |
|     └─ _updatedAt | int | 「更新时间」，Unix 时间戳 |
|     └─ _name | object | 「展示名称」，公式字段 (多语) |
|       └─ zh_cn | string | 中文内容 |
|       └─ en_us | string | 英文内容 |
|     └─ text_describe | string | 「工单描述」 |
|     └─ option_satisfaction | string | 「客户工单满意度」选项：满意 (option_satisfied), 一般 (option_generally), 不满意 (option_dissatisfied) |
|     └─ text_6f3346e6b64 | string | 「GCP工单号」 |
|     └─ text_result | string | 「工单处理结果」 |
|     └─ lookup_handler | object | 「当前处理人」，关联「用户」对象 |
|       └─ _id | string | 关联用户对象的记录 ID |
|     └─ _createdBy | object | 「创建人」，关联「用户」对象 |
|       └─ _id | string | 关联用户对象的记录 ID |
|     └─ lookup_creator | object | 「工单发起人」，关联「用户」对象 |
|       └─ _id | string | 关联用户对象的记录 ID |
|     └─ autoid_no | string | 「工单编号」 |
|     └─ text_title | string | 「工单标题」 |
|     └─ lookup_company | object | 「客户名称」，关联「客户公司」对象 |
|       └─ _id | string | 关联记录的记录 ID |
|     └─ datetime_proposed | int | 「工单发起时间」，Unix 时间戳 |
|     └─ datetime_report | int | 「客户报告时间」，Unix 时间戳 |
|     └─ datetime_resolved | int | 「工单关闭时间」，Unix 时间戳 |
|     └─ attachment_file | object[] | 「工单附件」，文件字段 |
|       └─ id | string | 文件的唯一标识 |
|       └─ size | string | 文件大小 |
|       └─ mime_type | string | 文件的 MIME 类型 |
|       └─ name | string | 文件名称 |
|     └─ formula_resolution | string | 「工单响应（分钟）」，公式字段 |
|     └─ option_status | string | 「处理状态」选项：待处理 (option_todo), 处理中 (option_inprocess), 待验证 (option_tobeconfirmed), 已关闭 (option_resolved) |
|     └─ option_type | string | 「工单类型」选项：问题处理 (option_cosultation), 操作变更 (option_defects), Billing问题 (option_issues), 技术方案或报价 (option_complaint), 其他事务 (option_sugesstion) |
|     └─ customer_reporter | string | 「客户提出人」 |
|     └─ lookup_product | object | 「所属产品」，关联「产品」对象 |
|       └─ _id | string | 关联记录的记录 ID |
|     └─ option_level | string | 「工单级别」选项：P1 (option_blocked), P2 (option_major), P3 (option_minor), P4 (option_38de4642f70) |
