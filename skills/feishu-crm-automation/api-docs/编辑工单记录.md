# 编辑工单记录

编辑「工单」对象中的指定记录。Tips：可在 “目录>历史版本” 的接口文档中查看历史接口

## 请求方式
PATCH

## 接口路径
/v1/data/namespaces/ticket_management__c/objects/object_order/records/:id

## 路径参数
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| id | 必填 string | 需要编辑的记录 ID | 12345678910 |

## 请求

### 请求头
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| Authorization | 必填 string | 传入应用 Token | T:f582c06c6ed14686b0ef... |
| Content-Type | 必填 string | 类型为 application/json | application/json |

### 请求体
| 名称 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| record | 必填 object | 需要更新的字段内容 | -- |
|   └─ lookup_c5de0a7f9a4 | object[] | 「抄送」，关联多条「用户」记录 | -- |
|     └─ _id | string | 关联用户对象的记录 ID | "100" |
|   └─ lookup_product | 必填 object | 「所属产品」，关联「产品」对象 | -- |
|     └─ _id | 必填 string | 关联记录的记录 ID | "100" |
|   └─ option_status | string | 「处理状态」选项：待处理 (option_todo), 处理中 (option_inprocess), 待验证 (option_tobeconfirmed), 已关闭 (option_resolved) | "option_todo" |
|   └─ customer_reporter | string | 「客户提出人」 | "Sample text" |
|   └─ text_6f3346e6b64 | string | 「GCP工单号」 | "Sample text" |
|   └─ option_type | 必填 string | 「工单类型」选项：问题处理 (option_cosultation), 操作变更 (option_defects), Billing问题 (option_issues), 技术方案或报价 (option_complaint), 其他事务 (option_sugesstion) | "option_cosultation" |
|   └─ text_describe | string | 「工单描述」 | "Sample text" |
|   └─ datetime_proposed | int | 「工单发起时间」，Unix 时间戳 | 1776319259239 |
|   └─ text_result | string | 「工单处理结果」 | "Sample text" |
|   └─ text_title | 必填 string | 「工单标题」 | "Sample text" |
|   └─ attachment_file | object[] | 「工单附件」 | -- |
|     └─ id | 必填 string | 文件的唯一标识 | "625d2f602af94d46972073db32a99ed2" |
|     └─ size | 必填 string | 文件大小 | "1024" |
|     └─ mime_type | 必填 string | 文件的 MIME 类型 | "jpg" |
|     └─ name | 必填 string | 文件名称 | "sample.jpg" |
|   └─ lookup_company | 必填 object | 「客户名称」，关联「客户公司」对象 | -- |
|     └─ _id | 必填 string | 关联记录的记录 ID | "100" |
|   └─ datetime_resolved | int | 「工单关闭时间」，Unix 时间戳 | 1776319259239 |
|   └─ datetime_report | 必填 int | 「客户报告时间」，Unix 时间戳 | 1776319259239 |
|   └─ option_satisfaction | string | 「客户工单满意度」选项：满意 (option_satisfied), 一般 (option_generally), 不满意 (option_dissatisfied) | "option_satisfied" |
|   └─ option_level | 必填 string | 「工单级别」选项：P1 (option_blocked), P2 (option_major), P3 (option_minor), P4 (option_38de4642f70) | "option_blocked" |
|   └─ autoid_no | string | 「工单编号」 | "100" |
|   └─ lookup_creator | object | 「工单发起人」，关联「用户」对象 | -- |
|     └─ _id | string | 关联用户对象的记录 ID | "100" |
|   └─ lookup_handler | object | 「当前处理人」，关联「用户」对象 | -- |
|     └─ _id | string | 关联用户对象的记录 ID | "100" |

## 响应
| 名称 | 类型 | 说明 |
| :--- | :--- | :--- |
| code | string | 响应码，0 代表成功 |
| msg | string | 响应描述 |
| data | object | 结果信息 |
|   └─ items | object[] | 更新后的记录快照（通常为空对象数组） |

### Python 示例：
```python
import requests
import json

url = "https://ae-openapi.feishu.cn/v1/data/namespaces/ticket_management__c/objects/object_order/records/12345678910"
payload = json.dumps({
  "record": {
    "text_describe": "Sample text",
    "text_title": "Sample text",
    "option_type": "option_cosultation",
    "customer_reporter": "Sample text",
    "lookup_product": {
      "_id": "100"
    },
    "text_6f3346e6b64": "Sample text",
    "attachment_file": [
      {
        "id": "625d2f602af94d46972073db32a99ed2",
        "size": "1024",
        "mime_type": "jpg",
        "name": "sample.jpg"
      }
    ],
    "datetime_report": 1776319462474,
    "option_status": "option_todo",
    "lookup_company": {
      "_id": "100"
    },
    "datetime_proposed": 1776319462473,
    "lookup_handler": {
      "_id": "100"
    },
    "lookup_c5de0a7f9a4": [
      {
        "_id": "100"
      }
    ],
    "option_satisfaction": "option_satisfied",
    "option_level": "option_blocked",
    "datetime_resolved": 1776319462474,
    "autoid_no": "100",
    "lookup_creator": {
      "_id": "100"
    },
    "text_result": "Sample text"
  }
})
headers = {
  "Authorization": "T:f582c06c6ed14686b0ef...",
  "Content-Type": "application/json"
}

response = requests.request("PATCH", url, headers=headers, data=payload)

print(response.text)
```
